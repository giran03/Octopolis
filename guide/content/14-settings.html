Settings

opens the Settings window. It has a search across every tab and an outline of the current tab's sections.

TabWhat is in it
GeneralFile Explorer (use Octopolis instead of it, add Open in Octopolis to its menu, the shortcut that brings Octopolis forward). Editor (the program, and whether double-clicking text and code uses it). Startup (what to open, the start folder, keep running in the notification area). Files and folders (hidden files, file extensions, Auto view, folder sizes, Windows file icons, image thumbnails, confirm before deleting). Copying and moving (confirm before moving folders, verify copies, speed limit, notifications, keep the PC awake). Terminal, editor and Git (shell, follow the current folder, hide ignored files, show last commit).
AppearanceTheme (theme, Windows light and dark pairing, accent, your themes, import, the theme gallery), Size and density (text size, interface font and Google Fonts, saved fonts, density), Icons (style, weight, size, presets, filled), Motion and help (animations, tooltips), Sidebar and shelf.
ShortcutsSearch and rebind every command, including your custom actions, with per-shortcut reset.
AdvancedYour data (settings folder, diagnostics log, back up and restore settings), cache management, clean up (folder rules, free up space, recent folders, folder icons, shelf) and reset.
UpdatesUpdate checks (off until a release feed is set up) and the changelog.
AboutVersion, links, welcome wizard, debug info, and this guide.
Back up before you experiment

Settings › Advanced can save all your settings to a file and restore them later, which also makes moving to a new PC easy.
