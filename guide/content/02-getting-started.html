Getting started

Install it, open a folder, and learn the five moves that make everything else easy.

First launch

Octopolis opens on your start folder (change it in Settings › General) with a short welcome tour. The window has a custom title bar with a go-to pill in the middle, a sidebar on the left (pinned folders, Quick access, recent folders, drives), your folders in the middle and a status bar at the bottom with the item count, selection size, the Git branch and the pane buttons.

If you ever want the tour again, run Show the welcome tour from the command palette.

The five moves

  1. Go anywhere with : type a few letters of a folder, a path, or a file in this folder. See the command palette.
  2. Open more places with tabs () and split panes (). Middle-click any folder to open it in a new tab.
  3. Find things with (filter this folder) or (search all subfolders). See Search and filters.
  4. Do things to files with the usual keys (copy, cut, paste, F2 rename, Del) or the right-click menu, which you can type to filter.
  5. Look at things with the inspector (Space) and Quick look ().

Use Octopolis instead of File Explorer

In Settings › General you can make Octopolis open the folders that other programs and Windows ask for: folders opened from the desktop, Start, the Run box and other apps, and Win E. You can turn it off at any time, and uninstalling also undoes it.

Prefer to keep File Explorer as the default? Add Open in Octopolis to Explorer's right-click menu for folders, drives and folder backgrounds instead. Uninstalling removes it.

Tray icon and summon key

  • One window. Only one Octopolis runs at a time: opening a folder, or starting it again, adds a tab to the open window.
  • Keep running in the notification area so it opens again instantly. Quit with or from the tray icon.
  • Summon key (optional): Ctrl E on the desktop or taskbar, or Ctrl Alt E anywhere, brings Octopolis forward.
  • Where I left off: reopening restores every pane and tab from your last session, and workspaces can be saved and reopened.
