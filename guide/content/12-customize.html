Customize

Make it yours

Themes, fonts, icons, density and motion. Everything lives under Settings › Appearance ().

Themes

{{themes}} built-in themes in six families. Click a card to preview it in this guide. In the app, each card has a Customize as a copy button. The theme picker groups them by family and shows a round color preview.

  • Follow Windows can use a different theme for light and for dark mode.
  • The accent color can be overridden on top of any theme.
  • Pick Match Octopolis at the top of this page to make the guide wear the theme you use in the app. It follows changes when you come back to this tab.

Theme creator

Settings › Appearance › New theme opens a creator with a live mock-up. Make as many themes as you like.

  • Pick every color, start from any theme, auto-shade the surfaces from three colors, or try a random palette.
  • It warns about hard-to-read colors and has a per-color undo.
  • Edit, duplicate, delete, copy as JSON, save as a file, or import from a file or text (single themes or lists). Imports accept only plain colors, so a shared theme can't smuggle in anything else.

Fonts, text size and icons

  • Interface font: any installed font, or one from a curated Google Fonts list. A Google font downloads when you choose it and can be saved on the PC to work offline; the uninstaller asks whether to remove saved fonts.
  • Text size scales the whole interface.
  • Icons: Material Symbols in Outlined, Rounded or Sharp, with weight, size, filled icons and presets.
  • Real Windows file icons appear in the list, with thumbnails for pictures and videos.

Density

Compact, Normal and Comfortable presets, plus an exact row-height slider (18 to 40 px). The whole chrome (sidebar, tabs, toolbar, menus, status bar) follows the density.

Animation

Animation level (System, Reduce or Full) controls the app's motion, and this guide follows it. With Reduce, everything here appears instantly.

Shortcuts and Vim keys

  • opens the shortcut editor. Change any shortcut, including two-step shortcuts (chords); a reset arrow beside a changed shortcut restores that one.
  • Vim keys are optional: h j k l, g g, G, y y, d d, p, v for visual selection and / to filter. Toggle them from the palette.
