Power tools

The things you reach for when a folder gets out of hand.

Duplicate finder

Groups identical files under a folder, biggest waste first, and moves the extra copies to the Recycle Bin. It can also look for similar pictures.

Disk space, sizes and clean-up

  • Folder sizes () add a size to every folder with proportional bars; a setting can calculate them automatically. The treemap () draws the folder as blocks.
  • Clean up a folder finds rebuildable folders, largest files, old large files, temporary files and empty folders, ready to move to the Recycle Bin.
  • Free up space (the broom button in the sidebar footer) finds caches, Windows Update leftovers, browser caches, developer caches and the Recycle Bin that are safe to delete, and previews everything before anything is removed.

Folder rules

Tidy a folder by moving old files elsewhere or sending them to the Recycle Bin. Open it from the rule button in the sidebar footer, the command palette (Folder rules) or Settings › Advanced. Every run is previewed first: you see the files and where each would go, and nothing changes until you confirm. A run can be undone with .

  • Presets give you a start: old installers, old PDFs to Documents, unfinished downloads, big and old files, pictures sorted by month and more. Adding one fills in your real Downloads, Documents and Pictures folders, and you can change anything afterwards.
  • Conditions: file names (*.pdf; invoice*), how long since the file last changed, an optional newest age, a minimum size in MB, and whether to include subfolders.
  • Sorted destinations: a move destination can use {year}, {month} and {ext}, so Pictures\{year}\{month} files each picture by the date it last changed.
  • Switch rules on and off in the list, Run all enabled to preview them together, or run one from the command palette (Run folder rule). Each rule remembers when it last ran.
  • Filter, duplicate, import and export rules as JSON, the same way as custom actions.

What is locking this?

shows which programs hold a file open, with the option to end them.

Custom actions

Your own commands in the right-click menu, in the command palette and on a shortcut. Open the manager with the button in the sidebar footer or Edit custom actions… in the palette.

  • Presets. 20 ready-made ones to start from, using only Windows' own cmd and PowerShell.
  • Each action can run in cmd or PowerShell, as administrator, with a confirmation, once per item, in a chosen folder, and can reload the folder when finished.
  • Limits. Restrict it to files or folders, to file types, to name patterns and to item counts.
  • Manage. Search, switch each on or off, duplicate, import and export as JSON. Every action gets a palette entry and a shortcut slot in Settings › Shortcuts.

Placeholders are replaced when the action runs, and the editor shows a live preview of the finished command and warns when its program is missing:

PlaceholderBecomes
{path} {paths}The selected path, or all selected paths
{dir} {parent}The current folder; the folder above the item
{name} {stem} {ext}The file name, without extension, and the extension
{list} {pslist}A list of the selected paths for cmd, or for PowerShell
{pickfolder}A folder you choose when the action runs
{prompt:Label}Text you are asked for when the action runs

Built-in terminal

opens a terminal that follows the folder you browse, and moves the file list when you cd. Choose the shell in Settings. Folders can also open in your editor or an external terminal from the right-click menu.

Git

  • Status badges on files and folders, the current branch in the status bar, and an optional last commit column.
  • Right-click to stage, unstage and discard changes; the inspector shows a file's changes.
  • A command hides files Git ignores. In Auto view, repositories always use Details.
