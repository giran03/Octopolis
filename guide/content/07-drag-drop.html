Inside Octopolis

  • Dragging within a drive moves; across drives it copies. Hold Ctrl to force a copy.
  • Dropping items back into the folder they already live in does nothing, instead of moving them onto themselves.
  • Hold a dragged item over a folder, a breadcrumb or a tab and it opens, so you can drag into a folder several levels down in one go.
  • Drag to the edge of a pane to open a new pane there (see Split panes), or onto the Shelf, which opens by itself while you drag.
  • If an item with the same name already exists, a prompt asks: Replace, Replace if newer, Skip or Keep both, for all items or one by one.

Dragging out of Octopolis

Dragging selected files out works like Explorer: drop them in a File Explorer folder, a browser upload box, or a chat or mail app and they arrive as real files (moved or copied as the target decides). Drag as many as you like at once; anything Windows can't reference is skipped instead of failing the whole drag.

Dragging in from the web

Drag a picture, video or audio file from a web page onto a folder (or a folder row) to save it there. Files dragged in from other programs are copied in too.

Safe by design

Names are made safe, nothing is ever overwritten, links to your PC or a private network are refused, and a drop nobody handles no longer makes the window open the dropped item.

Clipboard

Files you copy or cut in Octopolis paste in File Explorer and other apps, and files copied there paste in Octopolis. You can also paste a screenshot or copied text as a new file, and Paste as link makes symbolic links, junctions or hard links.
