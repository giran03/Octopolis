Organize

Tags, colors, a shelf for collecting, grouping, and icons that tell folders apart.

Tags and color labels

Press to give files and folders tags and colors. They show in the list, are listed in the sidebar and are searchable with tag:. Tags follow items you move or rename in Octopolis.

The Shelf

Collect files from many folders (, or drag them in; it opens by itself while you drag), then copy or move them all at once into a folder.

Group by

Right-click the list background (or use the command palette) to group by type, date modified, size or first letter. Grouping is remembered per folder.

Folder icons

Right-click a folder › Change icon. Pick from:

  • Emoji: a full emoji picker.
  • Windows icons: the colored icons of the special folders (Documents, Downloads, 3D Objects…), the icons of the apps in your Start menu, and every icon inside Windows' own icon files. Only icons this PC has are listed, and they load as they scroll into view.

A folder with a custom icon says so in its right-click menu: Change icon names what it wears, and Reset icon is marked Default.

Tab colors and pins

Pin and color tabs from their right-click menu so the places you live in are easy to spot.

Hidden files and extensions

shows or hides hidden files. Hide file extensions is in Settings › General. A command in the palette also hides files that Git ignores.
