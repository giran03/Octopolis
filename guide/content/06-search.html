Search and filters

Narrow a folder in a keystroke, or search every folder beneath it.

Quick filter

filters the current folder by name as you type, and you can also just start typing to jump to a matching item (type-to-find). Press Esc to clear it.

Search in subfolders

searches all subfolders with fuzzy matching as you type. Results are ranked by relevance and shown with their folder. is the flat view: every file in all subfolders in one sortable list. In the palette, the / prefix starts the same search.

Search filters

Add filters to any search. They combine freely.

FilterExampleMeaning
ext:ext:pdf,docxOnly these file types
size:size:>100mbBigger or smaller than a size
dm:dm:week · dm:today · dm:2026-01-01..2026-03-31Date modified: today, this week, a day or a range
re:re:^IMG_\d+A regular expression
type:type:file · type:dirFiles or folders only
content:content:TODO ext:rsSearch inside files; the inspector shows the matching lines
tag:tag:workItems with a tag

Saved searches

Save a search to the sidebar (Save this search to the sidebar… in the palette) and run it again with one click.

Selecting by rule

  • selects all and inverts the selection.
  • selects by pattern: *.jpg; IMG_*, or re: for a regular expression.
  • Select items of the same type is in the palette and the right-click menu.
  • Drag a box to select items in the list (start from any column but Name) and in the grid views. Selecting several items shows their total size, a breakdown by kind and their date range in the inspector.
