Troubleshooting and FAQ

Quick answers to the things people ask most.

Does Octopolis replace File Explorer?

Only if you ask it to. Settings › General › File Explorer can make Octopolis open folders from the desktop, Start, the Run box, other apps and Win E. Turn it off at any time. Uninstalling also undoes it.

I changed a view, and now Auto doesn't pick it

A view chosen by hand sticks to that folder. Open the View menu and choose Auto (or press ) to hand the folder back. To stop Octopolis picking views at all, switch Auto off in Settings › General.

A file won't delete or move: "in use"

Select it and run What is locking this? (). It lists the programs holding the file, with the option to end them.

"Access denied" or a folder that won't open

Octopolis explains what happened in the folder itself, with a Try again button. For programs and scripts that need more rights, use Run as administrator ().

Thumbnails or icons are missing

Check Settings › General › Files and folders: Windows file icons and Image thumbnails must be on. Online-only OneDrive files never download just to show a thumbnail.

A shortcut does nothing, or does something else

Open the shortcut editor (), search for the command and see what it is bound to. A shortcut can only belong to one command. Inside text fields, most shortcuts are left alone so typing works; Vim keys (if on) only apply to the file list.

This guide doesn't match my theme

The guide gets your theme from Octopolis when it is opened from the app (F1, or Settings › About), and again each time you return to its tab. If you opened the file by hand, or pick another theme in the selector at the top, it uses that instead. Choose Match Octopolis to follow the app.

Starting over

Settings › Advanced › Reset all settings returns everything to its defaults. Back up first if you want to keep your themes, shortcuts and custom actions.

Found a bug, or missing something?

Settings › About has links to report it. Including the version (shown at the bottom of this page) and what you did helps.
